# 记事本安全验收

只在用户请求能力验收时使用。限于 Windows-MCP 的 9 个工具，不保存、不覆盖文件，不修改或关闭已有文档，不发送或更改系统设置。

1. `ControlStatus` 确认可操作；用不带截图的 `Snapshot` 观察。
2. 用 `App` 打开记事本，使用新建且已确认的空白页。普通提示按安全边界处理；没有可确认的空白页则停止。
3. 新观察确认焦点后，输入短标记 `DSH_SAFE_24_7K9`，`clear=false`、`press_enter=false`。短标记避免走长文本的剪贴板路径。
4. 新 `Snapshot` 从实际编辑器读回文本，与标记逐字符核对。
5. 获取记事本区域截图并实际查看图像；看不到图片就报告“截图返回成功，视觉验收未完成”。直接使用工具结果，不额外保存副本。
6. 保留未保存的测试页供用户查看。报告输入、读回、图像识别是否通过，以及具体失败原因。

验收结束立即停止，不自动扩展操作。不要以窗口或进程存在代替结果验证，不为清理再次截图。仅在已有清理授权且能力允许时处理本次冗余文件；Harness 内部附件继续由应用管理。
