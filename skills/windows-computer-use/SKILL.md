# Windows 电脑操作

用于用户指定的桌面任务。需要可用的 `mcp__windows__` 工具；本 Skill 不会安装工具或增加权限。开始输入前，阅读 [安全边界](references/safety.md)；若插件已将同一安全边界加入当前提示词，无需重复读取。

## 观察、操作与核验

1. 确认目标应用、预期结果与已有授权。调用 `ControlStatus`；用户正在输入或工具处于接管/暂停状态时停止输入，空闲后重新检查。不关闭控制协调保护。一次只让一个代理控制桌面。
2. 先获取不带图片的 `Snapshot`，确认目标窗口、焦点与可操作控件。文字不足、布局或视觉效果需要核对时，再获取目标区域截图。优先使用当前控件 label；坐标必须来自新的观察。
3. 每次点击、输入、滚动或切换窗口后，重新读取界面再决定下一步。发现焦点被用户或其他代理改变时，之前的控件引用与坐标作废。
4. 以界面实际文字、控件状态或所见图像核对预期结果。工具的“已点击”“已输入”“截图成功”回执不足以证明任务完成。视觉任务必须实际检查图片；模型无法看图时明确报告视觉验收未完成。动画或播放需多个时间点证据。

普通弹窗需先读清当前完整文字，文字缺失就看该弹窗区域的新截图。已确认只是任务内普通信息/错误提示，且关闭不会改变数据或权限时，可主动确认并继续，不逐次询问。内容不明就停；保存、丢弃、覆盖、删除、发送等按用户已有的对应授权处理，不把“确定”按钮本身当作授权。

工具参数错误、超时或路径问题先判断原因，再有限重试；相同失败不机械重复，不自行改权限、系统设置或模型路由。

## 截图和本次运行的临时文件

- 默认直接观察工具返回的图片，不另存重复副本。已有证据仍有效时，不为汇报、归档或清理重复截图；需要新的视觉判断时仍须重新观察。
- 用户要求图片交付或任务确需保留证据时才导出，并在当前上下文记录准确路径、当前任务创建证据、用途和保留要求；不为清单另建冗余文件。
- 仅在用户已授权本次临时文件收尾清理、工具支持的情况下，任务完成后逐个清理清单内已无用途的文件。不能只按文件名、后缀、目录或时间判断归属；不递归清空目录，不通过符号链接、联接或其他重解析点删除。
- 保留用户原有文件、交付物、指定证据、仍在使用及恢复排错需要的内容；安装依赖、配置、备份、共享日志、用户上传文件和其他任务的产物不属于可清理项。
- Harness 内部附件交由应用管理。缺少支持引用关系管理的删除接口时，不删除底层对象、不改写会话日志、不清空共享缓存。图片可能仍在会话内保留，不宣称任务结束会自动删除。
- 清理后核实是否移除，简短说明实际清理数量、保留项与受限原因。没有删除就不能说已删除；没有额外文件时不为清理新增截图或导出。
